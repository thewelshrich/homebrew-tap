# Schooner Homebrew Tap

Official Homebrew formulae for [Schooner](https://github.com/thewelshrich/schooner).

Formula updates are proposed from Schooner's verified, immutable GitHub
Releases. Installation becomes public only after the corresponding formula has
passed this tap's macOS and Linux checks.
